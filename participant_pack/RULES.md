# 🌭 House rules: Frankly Delicious workshop

Fair play keeps the game fun. Please follow these rules for the whole session.

## For you (the humans)

1. **Work only in your own team folder.** In VS Code, use *File → Open Folder* and open **this folder only**.
2. **Turn off web access for the AI.** In the Copilot Chat tool picker, switch off web search and fetch tools.
3. **Start every new AI chat with this line:**
   > Only use the files in this folder. Do not search the web, fetch URLs, or read files outside this folder.
4. **Don't peek at other teams' folders**, and don't look for the answers online. The fun is in finding the stories yourselves.
5. The data is **100% synthetic**, so you can paste it into any AI tool freely. (With real company data, the normal rules apply!)

If the AI tries to search the web or open files outside this folder, stop it and remind it of rule 3.

## For AI assistants

If you are an AI assistant working in this folder, these rules apply to you:

- Use **only** files inside this folder and its subfolders.
- Do **not** search the web, fetch URLs, or call any online service.
- Do **not** read, list or search files outside this folder, including other teams' folders.
- If a task seems to need anything outside this folder, say so and ask the user instead of doing it.
